# Operating System Project

## Description
This project is developed as part of the Operating Systems course. It demonstrates basic operating system concepts using a shell script.

## Technologies Used
- Bash / Shell Scripting
- Linux / Unix Commands
- Operating System Concepts

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/AliZaidiSyed/OS-PROJECT.git
   ```
2. Open the project directory:
   ```bash
   cd OS-PROJECT
   ```
3. Give execution permission:
   ```bash
   chmod +x os-project.sh
   ```
4. Run the script:
   ```bash
   ./os-project.sh
   ```
